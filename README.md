# ATM Banking Application

A desktop application that simulates basic ATM banking functions through a graphical user interface.

## Features

- User login and account authentication
- View current account balance
- Deposit money into an account
- Withdraw money from an account
- Input validation for invalid transactions
- CSV-based user account storage
- Account balance updates after transactions
- PyQt6 graphical interface

## Technologies

- Python
- PyQt6
- CSV File Handling
- Object-Oriented Programming
- Git / GitHub

## Installation

git clone ... cd ATM-Project pip install -r requirements.txt python main.py

## How It Works

The application reads user account information from a CSV file and allows a user to log in to their account. After authentication, the user can view their balance, make deposits, and withdraw funds. The program validates transactions and updates the stored account balance when changes are made.
